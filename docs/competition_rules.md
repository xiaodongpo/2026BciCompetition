# 比赛接口与约束摘要

本文件是面向实现的摘要，不替代官方规则。原始操作细则、数据说明、决赛示例和现场流程文件不随仓库发布，其再分发许可未确认。

初赛要求单通道250 Hz、六秒内原始输入、因果推理及连续分块输出，允许已到达无标签数据的自动在线适应。早期严格窗模型没有持久适应；D2和R0利用该适应条款，必须分别说明原始窗口与更长的统计历史。不能将“因果”与“六秒端到端支持”混为一谈。

决赛要求Linux x86-64 CPU离线运行，`filter_eeg`输出等长的一维因果滤波信号；`predict`接收六秒窗和十段30秒参考，不依赖其他待测窗、调用顺序、过去预测或真实标签。参考可用于归一化，模型参数固定。每位受试者的AUC与ACC均值再等权平均；这不同于初赛bACC口径。现场时间要求为10条约30分钟记录合计不足60分钟。

发布代码保留训练和推理实现。GitHub整理不代表再次提交赛事，不创建或推送新的比赛镜像。本机轻量测试不代替官方CPU环境下的全量运行时验证。

原官方示例的自测函数已从公开候选的 `solution.py` 移除，替换为独立编写的本地协议工具 `protocol.py`；滤波与分类计算保持原实现，参考抽样的随机调用顺序通过等价检查核验。
