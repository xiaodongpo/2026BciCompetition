# 数据准备与版本

仓库不分发比赛 EEG、事件标签、受试者资料或官方文档。比赛允许训练并不自动授权再分发；数据须由研究者向权利方取得合法使用权限。本项目没有可确认的公开下载链接。

每份记录一个目录，包含一个 BDF+C 和一个 `*_events.csv`，数据集共57条记录，编号032和033缺失。单通道、250 Hz；MNE 读取的伏特转换为微伏。事件列为 `local_time,event,phase,key`；按完整 `trial_start` / `trial_end` 配对，`relax=0`、`task=1`，按键不是独立 trial。使用真实阶段时长。未标注前后缀不能作为有监督训练标签。

```text
authorized_data/
  001/
    001_YYYYMMDD_HHMMSS.mmm_UTC+0800.bdf
    001_events.csv
  ...
```

时间原点采用文件名的 UTC+08:00 毫秒时间，不采用 MNE 将本地 BDF 头部解释成 UTC 后的时间。早期路线用 ceil 映射，D2/H1 保留其原始 round 对齐方式，R0 用100纳秒整数时间计算。不能无说明地互换这些实现。

BAD_ACQ_SKIP 必须按其真实时间保留间断，禁止删除缺失样本后拼接。BDF 数字补零可能表现为约0.024微伏；饱和约±403333微伏。质量规则因路线而异，见对应预处理源码。原始文件只读，缓存另存。

记录编号不是已核实的受试者编号。原项目发现记录时间重叠，故记录级划分不等于严格受试者独立或采集片段完全独立。45/12、46/11及R0采集组评估不是可以混用的划分。

R0工程说明记载曾更换为更新版原始数据，不能默认早期目录、R0包内目录及H1目录完全相同。复现时使用对应训练来源的数据版本，并保留本地文件哈希清单。公开版本只提供程序和冻结记录划分，不公开带真实文件名和时间戳的原始清单。

```bash
python scripts/validate_data.py --data-root /path/to/authorized_data --output cache/private_data_manifest.json
python scripts/run_route.py --data-root /path/to/authorized_data h1 scripts.finals.build_cache
```

第一个命令验证记录数量、通道、采样率、文件名时间格式、事件字段并记录SHA-256；不等同于完成全部标签与重复记录审计。实际训练加载器继续处理事件配对及缺失。输出可能含私有元数据，已由 `cache/` 排除。

同一缓存目录不得更换数据版本后直接复用。H1/D2原缓存命中逻辑不全面校验原始文件哈希，换数据时使用新的仓库副本或新的缓存位置，并重新生成缓存。
